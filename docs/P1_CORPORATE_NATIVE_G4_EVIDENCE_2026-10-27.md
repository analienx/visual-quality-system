## Two real Region actions, source-bound to independent Modeling DAX

Under the **same** native PID/model/source revision, the independent DAX oracle executed two separate text-fingerprinted queries:
- `kpi_europe`: Actual, Plan, variance, and variance percentage with explicit `Sales Region = Europe` filter.
- `kpi_all`: the same four measures with no Sales Region filter.

Both queries verified arithmetic consistency, exact local model identity, saved-source digest, source and query fingerprint, and no source change during query execution.

Native Windows UI Automation captured a **read-only baseline** and **two explicit `TogglePattern` operations** on the *Sales Region* slicer, with all option states and the visually rendered **Var to Plan %** card:

| Ordered native event | Verified UIA before → after | Independently executed DAX comparison |

**Count: 2 actual native actions plus 1 read-only baseline; not 3 actions.** The live KPI readback used the actual Desktop accessibility tree, not mouse coordinates, inferred source values or a synthetic pass. No exact private financial values are replicated in this public document.

The event authoring script checked unique OS-owned PID/path, scoped UIA combobox/list/option control types, allowed `TogglePattern`, reported pre/post raw states, and read the native percentage KPI `DataItem`. A separate read-only verifier then checked event order, all percentages against the **actual executed DAX**, arithmetic, timestamp chronology, unchanged source *bytes and timestamps* against the saved witness, terminal same OS/Bridge model/report PID, individual evidence file SHA-256 and simple tampered-value negatives. It wrote a **new self-contained private standardized event receipt**, without manufacturing or backdating any missing actions.

After the native transitions, the Desktop in-memory dirty flag was **true**. This means a new *saved-file attestation* correctly remains `status=blocked`; the terminal **interaction transaction identity** was separately verified. No repeat Save/reopen solely to clear the flag.
