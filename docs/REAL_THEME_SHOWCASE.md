# Native Power BI Desktop theme gallery

**Five selected palettes, ten modes, 30 genuine Power BI Desktop report screenshots.**
Each mode comes from its own GitHub-generated candidate of the same synthetic Contoso PBIP
and was refreshed in an isolated Power BI Desktop session before native page capture.
Original PNGs remain private; public WebP files crop only Desktop chrome and downscale.
No invented dashboards, synthetic diagram screenshots, or image AI.

Theme-engine capture code: [`a2bd3662be`](https://github.com/analienx/visual-quality-system/commit/a2bd3662be9974714eba9fb889137349752cd1df).

## Evidence boundaries

Microsoft report authoring/schema validation applies to all 28 modes.
Native screenshot evidence here applies **only** to these five selected
families and the depicted default-page states. Filter dropdown flyouts,
country-shape selection, other palettes' live rendering, and separate
independent G2/G6 acceptance are not certified by these images.
The historical five-colorway [Desktop gallery](THEME_GALLERY.md) remains available.
